# Moto Warranty Triage

Warranty claims backend for an electric motorcycle maker: a NestJS API runs a Python triage agent (Claude Agent SDK) as a retried, idempotent background job.
![Demo](https://github.com/ArchiusVuong-sudo/moto-warranty-triage/releases/download/v0.1/demo.gif)

Full video: https://github.com/ArchiusVuong-sudo/moto-warranty-triage/releases/download/v0.1/demo.mp4


Synthetic data. Replay mode. AI: live. ANTHROPIC_API_KEY. Dealer Northgate Moto Works, bike models Ridgeback MX, Talus Enduro, Kestrel SM. Fault code BMS-CELL-DELTA. Python, FastAPI, PGlite, NestJS 12, Express 5, React, Tailwind.
